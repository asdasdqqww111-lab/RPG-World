# توثيق الأصول

## خامة الأرض

لم تُضف خامة أو صورة خارجية في هذا الإصدار. يستخدم المشهد مادة `StandardMaterial3D` بسيطة بلون أخضر مطفأ معرفة ضمن `scenes/world/flat_terrain.tscn`، وهي مادة مولّدة من إعدادات Godot وليست أصلًا منقولًا؛ لا تتطلب ملفًا أو نسبة لمصدر خارجي.

تم فحص المرشح الأولي [fabien-michel/sweethome3d-textures-ambientcg](https://github.com/fabien-michel/sweethome3d-textures-ambientcg): صفحة المستودع وملف `LICENSE` يعلنان CC0 1.0، كما يذكر README أن الصور مشتقة من ambientCG وأن المؤلف الأصلي هو Lennart Demes. لكن المستودع عبارة عن مُولّد/مجموعة كبيرة وليس توثيقًا لملف خامة PBR محدد مناسبًا للمشروع؛ لم يتم تنزيل صورة بعينها أو التحقق من خرائطها الفعلية وأصلها الفردي. لذلك لم يُدرج أي ملف منه، ولم يُفترض أن وجود ترخيص للمستودع وحده يثبت ترخيص كل أصل مطلوب.

عند إضافة خامة لاحقًا، يجب تسجيل رابط صفحة الأصل المباشر، المصدر/المؤلف، الترخيص الذي ينطبق على ذلك الملف، أسماء الخرائط المستخدمة وأبعادها، ثم ضبط UV أو التكرار بوحدات مترية واختبار مظهرها داخل Godot. لا تُستخدم أصول مشكوك بترخيصها.
