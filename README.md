# RPG World — نموذج الأرض المسطحة

نموذج أولي لمشروع RPG على Godot 4، والمرحلة الحالية تقتصر على أرض مسطحة قابلة للاختبار. لا توجد شخصية أو أنظمة لعب أخرى بعد.

## التوافق والتشغيل

- إصدار الاستهداف: **Godot 4.4.1 Standard**. ملفات المشروع تستخدم صيغة Godot 4؛ لم يتوفر محرّك Godot في بيئة إعداد هذا التغيير، لذلك لم يُجرَ استيراد أو تشغيل فعلي ولم يتم التحقق من رقم إصدار محرّك مستخدم للاختبار.
- افتح Godot Project Manager، اختر **Import**، ثم حدّد مجلد المستودع أو ملف `project.godot`، وافتح المشروع وشغّله عبر **F6** أو **F5**. المشهد الرئيسي مضبوط في `project.godot`.
- إعداد العرض يستخدم **GL Compatibility** لزيادة التوافق مع الأجهزة المحمولة والعتاد الأقدم. هذا اختيار توافق وليس ضمانًا للأداء؛ يلزم اختبار على الأجهزة المستهدفة.
- لا يوجد إعداد تصدير Android أو اعتماديات إضافية في هذه المرحلة. إعداد Android يحتاج Android SDK وJDK متوافقين مع نسخة Godot وأدوات التصدير، ولم يتم تثبيتها أو التحقق منها هنا. لا تحفظ مفاتيح توقيع أو بيانات اعتماد في المستودع.

## المشهد والأرض

- المشهد الرئيسي: `scenes/main.tscn`.
- مشهد الأرض: `scenes/world/flat_terrain.tscn`.
- سطح `PlaneMesh` أفقي في مستوي XZ، أبعاده `1000 × 1000` متر، ومركزه `(0, 0, 0)`، وحدوده `-500..+500` على X وZ، وعلى ارتفاع `Y=0`.
- اصطدام الأرض `StaticBody3D` يستخدم صندوقًا مركزيًا سماكته `0.1` متر، ومركزه عند `Y=-0.05`؛ لذا تقع قمته عند `Y=0` وتطابق مساحة الأرض.
- خامة مؤقتة بلون أخضر مطفأ معرفة داخل مشهد الأرض ولا تحتاج ملف صورة. لاستبدالها، عدّل `StandardMaterial3D` المسمى `GroundMaterial` في `flat_terrain.tscn` أو اربط خامة من `assets/materials/`. لم تُضف صورة أو خامة خارجية؛ انظر `docs/ASSET_CREDITS.md`.
- الكاميرا والإضاءة في المشهد الرئيسي لأغراض العرض والاختبار فقط.

## Android

للتصدير لاحقًا، ثبّت Android build template وAndroid SDK وJDK المتوافقين من تعليمات Godot الرسمية، ثم عرّف مسارات الأدوات داخل محرر Godot وأضف preset تصدير مناسبًا. لم يتم إعداد التصدير أو اختباره في هذا النموذج.
